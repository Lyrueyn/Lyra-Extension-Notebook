# 笔记本扩展

璃鸢镜的本地优先笔记本扩展。一个 `.lyrnb` 文件包含多篇笔记。

## 当前版本

- 左侧「笔记」Tab：打开已有 `.lyrnb` / 新建笔记本
- 一个笔记本内多篇笔记
- 富文本编辑：标题、正文、粗体/斜体/下划线/删除线、行内代码（可再次点击取消）、链接、列表、待办、引用、代码块、分割线、文字颜色/高亮
- 列表支持 Tab 缩进 / Shift+Tab 减少缩进，子列表按结构保存
- 图片：工具栏选择/粘贴/拖入，图片按 SHA-256 存进 `.lyrnb` 的 `assets/`
- 表格：插入行×列，单元格直接编辑，结构保存为二维单元格数组
- 段落样式改为跟随当前段落的左侧按钮，不再在顶部下拉选择
- 自动保存，宿主原子写回
- `.lyrnb` 结构：ZIP + `manifest.json` + `notes/<id>.json`，不存 HTML

## 说明

- 文件格式为自定义结构树，HTML 只在粘贴/导出阶段使用。
- 图片、表格、PDF 导出等后续版本再加。
